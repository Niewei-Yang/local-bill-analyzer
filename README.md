# 个人账单分析

汇总微信、支付宝与校内收入账单，查看收支趋势、消费分类和每日明细。支持云端访问与本地运行，重复导入同一账单不会重复记账；再次导入包含同一订单的新版本时，会更新交易状态和内容。

云端由 Vercel 托管，使用 Neon/PostgreSQL 持久保存账本，并通过独立用户名和密码登录。配置、原有账本迁移及备份恢复方法见 [DEPLOY.md](DEPLOY.md)。

## 云端使用

打开[个人账单分析](https://neewii-bill.vercel.app)，使用设置的账号密码登录，即可查看和导入账单。同一云端账本可在电脑和手机上访问；刷新页面或重新部署后，已导入的记录仍会保留。

## 本地运行

双击 `启动账单分析.cmd`，浏览器会自动打开：

```text
http://127.0.0.1:8765
```

未配置 `DATABASE_URL` 时，账本默认保存在 `data/bills.db`。本地运行与云端使用各自的账本，不自动同步；可通过导出备份和恢复账本进行迁移。

## 导入与分析

在页面右上角点击“导入新账单”，可以一次选择多个文件。支持：

- 微信支付导出的 `.xlsx`
- 支付宝导出的 `.csv`，自动识别 GB18030/GBK 与 UTF-8 编码
- 财务系统「学生收入查询」导出的校内收入 `.xls`

趋势图支持按月、按周和按天查看。点击柱形或横轴时间标签，会把主要支出类别、消费时间热力、商户排行、最高支出和最近交易切换到该时段；再次点击同一时段会取消选择。按天查看时显示最高支出单笔，最近交易超过 30 笔时可以翻页。周统计按周一至周日计算。

云端导入时，文件会上传到服务端进行解析，解析后的交易保存到云数据库；原始文件不作为附件永久保存。本地运行时，文件由本机服务解析。

顶部勾选“排除单笔 ≥ 1000 元支出”后立即刷新统计，包含恰好 1000 元的支出；概览、趋势、分类、商户排行、累计曲线、每日明细和交易分页均沿用此筛选。收入、退款和微信收款（转账、二维码收款）抵扣仍按原规则统计。取消勾选或点击“清除”可恢复全部支出，原始账单不受影响。

趋势柱状图中每个分类只绘制一次，“其他”合并未单列的分类。类别净支出为负时绘制在零线下方，柱顶数字为包含所有类别抵扣后的净支出，与时段明细一致。

月度柱状图另将校内税后“实发金额”按月汇总，用紫色独立负柱向下堆叠，不合入“其他”；悬停可查询当月税后收入。柱顶仍为净支出（未减校内收入），与累计支出折线口径一致。只有校内收入的月份也会显示并可点击查看，日期和平台筛选照常生效；周/日柱状图沿用净支出口径。

页面右上角可“导出备份”或“恢复账本”，云端与本地均使用兼容的 SQLite 备份文件。恢复会替换当前账本，并先自动备份原账本：云端备份存入云数据库，本地备份存入数据库所在目录。只接受结构兼容且完整性检查通过的备份文件。

按周或月选中时段后，详情中还会显示每日累计净支出曲线。退款和微信收款（转账、二维码收款）按发生日期抵扣，无交易日延续前一天累计值；悬停、点击或键盘聚焦圆点可查看每日金额。趋势图上方可输入月参考额度（默认 4500 元，支持零额度及两位小数），修改后立即更新曲线并保存在当前浏览器。周额度按周一至周日每天的 `月参考额度 / 当月天数` 相加，跨月分别折算，最后保留两位小数。日期筛选或数据不足整期时，曲线仅累计当前范围内的账单，额度线仍代表整月或整周。

点击累计曲线上的圆点，可在曲线下方查看当天全部支出、退款和微信收款（转账、二维码收款）（时间、平台、商户、商品说明、分类、金额），并核对各项抵扣及净支出合计。明细沿用当前平台筛选；没有支出、退款或微信收款（转账、二维码收款）时显示空状态。键盘聚焦圆点后按 Enter 或空格也可展开。

累计曲线还包含绿色的计划累计支出线，按每天所在月份的 `月参考额度 / 当月天数` 累加，跨月周分别折算，累计结果再保留两位小数。实际与计划都从当前显示范围首日开始累计；无交易日计划仍增长。圆点提示同时显示计划累计金额及实际超出或低于计划的差额，修改月额度后同步更新。

月/周详情的累计折线图另有紫色“校内税后收入累计”线，按学校账单税后“实发金额”及入账日期逐日累计，无收入日延续前值。只在当天有校内收入时显示紫色圆点，悬停或聚焦可查看当天收入及累计收入；纵轴自动涵盖收入金额。收入与支出沿用同一日期、平台和大额支出筛选，从当前显示范围首日累计；校内收入不抵扣净支出。

最新显示月份的累计图横轴延伸到该月最后一天（自动适配每月天数及闰年），实际支出、校内收入及其圆点只绘制到所选账单范围截止日。截止日之后保留空白，绿色计划累计虚线和橙色额度虚线继续显示到月底；原有统计和交易筛选范围不变。

## 命令行

```powershell
# 启动本地页面和 API
python app.py serve

# 导入一个或多个账单
python app.py import "微信账单.xlsx" "支付宝账单.csv"

# 输出当前统计结果
python app.py stats

# 指定其他数据库
python app.py --db "D:\账单数据\bills.db" serve
```

首次运行若提示缺少 `openpyxl`：

```powershell
python -m pip install -r requirements.txt
```

## 数据与统计口径

- 金额以“分”存储，避免浮点累计误差。
- 订单号存在时，以“平台 + 订单号”去重；没有订单号时，用时间、金额、方向、商户、说明和支付方式生成稳定指纹。
- 同一订单内容或状态改变时更新原记录。
- 净支出 = 支出交易原额 − 退款记录金额 − 微信收款（转账、二维码收款）。
- 非退款收入不包含退款。
- 校内收入按税后“实发金额”入账，并使用校内流水号去重；交易时间取凭证日期，没有凭证日期时取录入日期，状态记录是否已制证，备注合并部门名称与项目名称。
- 学生收入查询会导出入学以来的全部记录，但支出账单最多只能导出近一年（账本数据从 2025-09 开始），所以校内收入只导入支出数据起始月份（含当月）之后的记录，更早的不入账；被时间窗挡下的行数在导入结果的 `excluded` 里。
- 支付宝优先使用原始分类；微信默认按交易类型、商户和商品关键词分类。
- 页面中的自定义规则按优先级执行，可立即重算历史数据，也会用于以后导入。
- 对原规则未识别的交易，补充红包/提现、还款、停车充电、运动健身、打印、常见餐饮品牌等识别；退款也使用这些补充规则。已有明确分类和自定义规则优先，只有姓名或模糊描述的交易保留为“其他”。
- 商户规则核对参考：[湖北笑联的校园生活服务介绍](https://www.zhaopin.com/jobdetail/CCL1373451990J40754904111.htm)、[昌顺马记餐饮介绍](https://www.visitbeijing.com.cn/article/4CHG2fu465V)。这些规则仅识别账单用途，不推断具体购买项目。

## API

云端 API 使用网站的同一域名，并要求账号密码认证；本地启动默认绑定 `127.0.0.1:8765`。除数据库备份下载外，响应均为 JSON。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/health` | 健康检查 |
| `GET` | `/api/meta` | 数据库、分类和支持格式 |
| `GET` | `/api/dashboard` | 概览、趋势、分类、时段、商户和最近交易 |
| `GET` | `/api/transactions` | 分页交易明细 |
| `GET` | `/api/imports` | 导入历史 |
| `POST` | `/api/import` | 上传一个账单文件 |
| `GET` | `/api/database/export` | 下载一致的 SQLite 数据库快照 |
| `POST` | `/api/database/import` | 校验并恢复 SQLite 数据库 |
| `GET` | `/api/rules` | 获取自定义分类规则 |
| `POST` | `/api/rules` | 新增分类规则 |
| `DELETE` | `/api/rules/{id}` | 删除分类规则 |
| `POST` | `/api/reclassify` | 按当前规则重算全部分类 |

`/api/dashboard` 和 `/api/transactions` 支持查询参数：`start=YYYY-MM-DD`、`end=YYYY-MM-DD`、`platform=微信|支付宝|校内收入`、`category=分类名`、`exclude_large_expenses=true`（排除单笔大于等于 1000 元的支出）。仪表盘另支持 `granularity=month|week|day`，周以周一为起始日；交易明细另支持 `page`、`size`。

### 上传文件

`POST /api/import` 使用原始文件内容作为请求体，并通过 `X-Filename` 传入 URL 编码后的文件名：

```javascript
await fetch("/api/import", {
  method: "POST",
  headers: {
    "Content-Type": "application/octet-stream",
    "X-Filename": encodeURIComponent(file.name)
  },
  body: file
});
```

### 新增分类规则

```json
{
  "field": "counterparty",
  "pattern": "麦当劳",
  "category": "餐饮",
  "priority": 200,
  "apply_existing": true
}
```

可用字段：`all`、`counterparty`、`description`、`category_raw`、`payment_method`、`status`。

## 扩展新的账单来源

1. 在 `bill_analyzer/importers.py` 中新增 `BillImporter` 子类。
2. 实现 `score(filename, content)` 与 `parse(filename, content)`。
3. 把实例加入 `IMPORTERS` 列表。

解析器只需输出统一的 `Transaction`，数据库、去重、分类和全部统计接口会自动复用。

## 备份

云端和本地均可在页面点击“导出备份”，下载完整账本；需要恢复时点击“恢复账本”。云端网页导入/导出上限为 4 MiB，较大账本使用 [命令行迁移工具](DEPLOY.md)。

本地也可停止服务后复制 `data/bills.db`，恢复时把文件放回原位置。不要在服务运行中只复制单个 `bills.db`，因为 SQLite WAL 模式可能同时存在 `-wal` 文件。
